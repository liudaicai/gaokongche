# 物流台账页面使用说明

## 📋 功能概述

物流台账页面是一个全新设计的物流管理界面，提供以下核心功能：

### ✨ 主要特性

1. **自动记录**
   - 进场单创建时自动生成物流台账（物流成本 > 0）
   - 退场单创建时自动生成物流台账（物流成本 > 0）
   - 自动关联订单、设备、车辆/司机/物流公司信息

2. **手动创建**
   - 支持手动创建物流台账记录
   - 灵活的表单设计，适应不同业务场景

3. **多维度筛选**
   - 日期范围筛选
   - 记录类型筛选（进场/退场）
   - 物流类型筛选（自有物流/三方物流/客户自提）
   - 订单编号搜索
   - 台账编号搜索

4. **数据统计**
   - 总记录数统计
   - 总物流费用统计
   - 进场/退场记录数统计
   - 自有/三方物流记录数统计

5. **数据导出**
   - 一键导出为 CSV 格式
   - 包含所有关键信息

## 🔧 技术实现

### 前端组件

- **文件位置**: `src/features/logistics/LogisticsLedgerPage.tsx`
- **技术栈**: React + TypeScript + Ant Design
- **状态管理**: 本地 useState（无需 Redux）
- **API 调用**: 统一的 apiGet/apiPost 方法

### 后端 API

- **路由文件**: `server/routes/logistics.mysql.js`
- **主要端点**:
  - `GET /api/logistics/ledger` - 获取台账列表
  - `POST /api/logistics/ledger` - 创建台账记录
  - `GET /api/logistics/ledger/:id` - 获取单条记录详情

### 数据库表

- **表名**: `logistics_ledger`
- **关键字段**:
  - `ledger_number` - 台账编号（唯一）
  - `order_id` - 订单ID
  - `order_number` - 订单编号
  - `entry_id` / `exit_id` - 进场/退场记录ID
  - `logistics_type` - 物流类型（own/third/customer）
  - `record_type` - 记录类型（entry/exit）
  - `logistics_cost` - 物流费用
  - `record_date` - 记录日期

## 📝 使用流程

### 查看物流台账

1. 点击左侧菜单 "物流管理" → "物流台账"
2. 页面自动加载最近的台账记录
3. 查看统计卡片了解总体情况

### 筛选数据

1. 选择日期范围
2. 选择记录类型（进场/退场）
3. 选择物流类型（自有/三方/客户自提）
4. 输入订单编号搜索
5. 点击"查询"按钮

### 查看详情

1. 点击表格中的"详情"按钮
2. 弹窗显示完整的台账信息
3. 包括物流公司、车辆、司机等详细信息

### 手动创建台账

1. 点击"手动创建台账"按钮
2. 填写表单：
   - 订单编号（必填）
   - 记录类型（必填）
   - 物流类型（必填）
   - 物流费用（必填）
   - 记录日期（必填）
   - 备注（选填）
3. 点击"确定"提交

### 导出数据

1. 筛选需要导出的数据
2. 点击"导出数据"按钮
3. 自动下载 CSV 文件

## 🚀 自动记录功能

### 进场单自动创建

当创建进场单时，如果填写了物流成本（> 0），系统会自动：

1. 生成唯一的台账编号
2. 关联订单信息
3. 记录物流类型（自有/三方/客户自提）
4. 保存车辆、司机或物流公司信息
5. 记录物流费用和日期

### 退场单自动创建

退场单的自动创建逻辑与进场单相同。

### 查看自动记录

自动创建的台账记录会显示在台账列表中，可以通过：
- 订单编号关联查询
- 记录类型筛选（进场/退场）
- 日期范围筛选
