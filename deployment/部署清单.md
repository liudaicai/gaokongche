## 🚀 部署步骤

### 第1步：服务器准备
```bash
# 1. 安装Node.js 18+
node -v

# 2. 安装MySQL 5.7+/8.0+
mysql --version

# 3. 安装Python 3.9+（OCR服务）
python --version

# 4. 安装PM2（进程管理）
npm install -g pm2
```

### 第2步：上传代码
```bash
# 方式1：Git拉取（推荐）
git clone <your-repo-url>
cd <project-dir>

# 方式2：直接上传
scp -r d:/kaifa/4/* user@server:/path/to/app/
```

### 第3步：安装依赖
```bash
# Node.js依赖
npm install --production

# Python依赖（OCR服务）
cd python_services
pip install -r requirements.txt
```

### 第4步：配置环境
```bash
# 复制环境变量文件
cp .env.production .env

# 编辑配置
nano .env
```

**必须修改的配置**：
```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=gaokongche

JWT_SECRET=生成一个随机字符串

PYTHON_OCR_SERVICE_URL=http://localhost:5000
```

### 第5步：初始化数据库
```bash
# 登录MySQL
mysql -u root -p

# 执行Schema
source /path/to/sql/mysql/baseline_v1.0.sql

# 创建管理员
source /path/to/deployment/sql/02_create_admin_user.sql
```

### 第6步：启动服务
```bash
# 启动OCR服务（后台）
cd python_services
python ocr_service.py &

# 启动Node后端（PM2）
pm2 start npm --name "gaokongche-api" -- run api

# 构建前端
npm run build

# 使用Nginx托管前端静态文件
```

## 🔧 Nginx配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/app/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://localhost:3001/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # OCR服务代理
    location /ocr/ {
        proxy_pass http://localhost:5000/;
    }
}
```
