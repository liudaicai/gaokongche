```bash

```

## 🎯 三种部署方式

### 方式一：自动化部署（推荐，最快）⚡

```bash
# 1. 连接服务器
ssh root@your_server_ip

# 2. 确保已安装宝塔面板和基础环境
# （Node.js 18+, MySQL 8.0+, Nginx, PM2）

# 3. 克隆代码
cd /www/wwwroot
git clone https://github.com/liudaicai/gaokongche.git
cd gaokongche

# 4. 运行自动部署脚本
chmod +x scripts/deploy-baota.sh
./scripts/deploy-baota.sh

# 5. 按提示输入配置信息
# - 项目目录（默认：/www/wwwroot/gaokongche）
# - 数据库名称（默认：gaokongche）
# - 数据库用户名（默认：gaokongche_user）
# - 数据库密码（自定义）
# - API 端口（默认：3001）
# - 域名或 IP

# 6. 等待脚本自动完成所有步骤
# ✓ 依赖检查
# ✓ 安装依赖
# ✓ 配置环境变量
# ✓ 数据库迁移
# ✓ 构建前端
# ✓ 配置 PM2
# ✓ 配置 Nginx

# 7. 验证部署
./scripts/check-deployment.sh

# 8. 访问系统
http://your-domain.com
```

**预计时间：10-15分钟**

---

### 方式二：半自动部署（手动数据库 + 自动部署）

```bash
# 1. 在宝塔面板手动创建数据库
# 数据库 → 添加数据库
# - 数据库名：gaokongche
# - 用户名：gaokongche_user
# - 密码：生成强密码
# - 字符集：utf8mb4

# 2. 初始化数据库
mysql -u gaokongche_user -p gaokongche < sql/mysql/000_init_database_baota.sql
mysql -u gaokongche_user -p gaokongche < sql/mysql/200_add_multi_tenant_support_safe.sql
mysql -u gaokongche_user -p gaokongche < sql/mysql/215_create_blacklist_table.sql
mysql -u gaokongche_user -p gaokongche < sql/mysql/217_merge_finance_SUCCESS.sql
mysql -u gaokongche_user -p gaokongche < sql/mysql/221_add_finance_records_fields.sql

# 3. 运行自动部署脚本（跳过数据库迁移）
./scripts/deploy-baota.sh
# 在提示是否执行数据库迁移时选择 'n'
```

**预计时间：15-20分钟**

## 📋 部署前检查清单

在开始部署前，请确认以下条件：

### 服务器要求
- [ ] 已购买阿里云 ECS 服务器
- [ ] CPU: 2核及以上
- [ ] 内存: 4GB及以上
- [ ] 磁盘: 40GB及以上
- [ ] 操作系统: CentOS 7/8 或 Ubuntu 18/20/22
- [ ] 已配置安全组（开放 80, 443, 8888 端口）

### 域名和网络
- [ ] 已备案域名（中国大陆服务器必需）
- [ ] 已配置 DNS 解析指向服务器 IP
- [ ] 网络带宽至少 3Mbps

### 宝塔面板
- [ ] 已安装宝塔面板 7.x 或 8.x
- [ ] 已登录宝塔面板
- [ ] 已绑定宝塔账号（可选）

### 必要信息
- [ ] 服务器 IP 地址
- [ ] SSH 登录密码
- [ ] 宝塔面板登录信息
- [ ] 数据库密码（准备一个强密码）

## 🛠️ 常用运维命令

### 服务管理
```bash
# 重启后端
pm2 restart gaokongche-api

# 重载 Nginx
nginx -s reload

# 重启 MySQL
systemctl restart mysql

# 查看服务状态
pm2 status
systemctl status nginx
systemctl status mysql
```

### 日志查看
```bash
# 后端日志
pm2 logs gaokongche-api
tail -f logs/error.log

# Nginx 日志
tail -f /www/wwwlogs/gaokongche_error.log

# MySQL 日志
tail -f /www/server/data/mysql-error.log
```

### 数据备份
```bash
# 手动备份数据库
mysqldump -u gaokongche_user -p gaokongche > backup_$(date +%Y%m%d).sql

tar -czf gaokongche_backup_$(date +%Y%m%d).tar.gz /www/wwwroot/gaokongche
```
