## 🎯 快速部署（5分钟）

### 准备
```bash
# 确保已安装
node -v     # 18+
mysql --version  # 5.7+/8.0+
python --version  # 3.9+
```

### 步骤1：数据库
```bash
mysql -u root -p
> source d:/kaifa/4/sql/mysql/baseline_v1.0.sql;
> source d:/kaifa/4/deployment/sql/02_create_admin_user.sql;
> exit
```

### 步骤2：配置
```bash
cd d:\kaifa\4
cp .env.production .env
notepad .env  # 修改数据库密码和JWT_SECRET
```

### 步骤3：启动
```bash
npm install
npm run api  # 后端
npm run dev  # 前端（新终端）
```
