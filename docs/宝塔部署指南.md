# 高空车租赁管理系统 - 阿里云宝塔部署指南

## 一、服务器准备

### 1.1 服务器配置推荐
- **CPU**: 2核及以上
- **内存**: 4GB及以上
- **磁盘**: 40GB及以上
- **操作系统**: CentOS 7.x / 8.x 或 Ubuntu 18.04 / 20.04 / 22.04
- **网络**: 带宽至少 3Mbps

### 1.2 安全组配置
在阿里云控制台配置安全组，开放以下端口：
- `22` - SSH（用于远程连接）
- `80` - HTTP
- `443` - HTTPS
- `8888` - 宝塔面板（可自定义）
- `3306` - MySQL（可选，建议仅内网访问）
- `3001` - Node.js 后端（可选，建议仅内网访问）

## 三、安装运行环境

### 3.1 一键安装套件（推荐）
登录宝塔面板后，选择 **LNMP（推荐）** 套件安装：
- **Nginx**: 1.20+ 版本

### 3.3 验证安装
在宝塔终端或 SSH 中执行：
```bash
node -v    # 应输出 v18.x.x 或更高
```

## 四、数据库配置

### 4.1 创建数据库
1. 点击左侧菜单 **数据库**
2. 点击 **添加数据库**
   - **数据库名**: `gaokongche`
   - **用户名**: `gaokongche_user`（自定义）
   - **密码**: 生成强密码（保存好）
   - **访问权限**: `本地服务器`（推荐）或 `所有人`
   - **字符集**: `utf8mb4`
   - **排序规则**: `utf8mb4_unicode_ci`

### 4.2 配置 MySQL
1. 点击 **数据库** -> **MySQL 8.0** -> **设置**
2. 修改配置文件（添加以下内容到 `[mysqld]` 部分）：
```ini
[mysqld]
# 基本配置
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci
max_connections=1000
max_allowed_packet=256M

# 性能优化
innodb_buffer_pool_size=1G
innodb_log_file_size=256M
innodb_flush_log_at_trx_commit=2
innodb_flush_method=O_DIRECT

# 时区设置
default-time-zone='+8:00'

# SQL 模式（兼容性）
sql_mode=STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION
```
3. 保存后重启 MySQL 服务

### 4.3 导入数据库结构
```bash
# 方式1: 通过宝塔面板导入
# 数据库 -> 点击数据库名 -> 导入 -> 选择 SQL 文件

# 方式2: 通过命令行导入（推荐用于大文件）
cd /www/wwwroot/gaokongche/sql/mysql
mysql -u gaokongche_user -p gaokongche < 001_initial_schema.sql
```

## 九、配置 Nginx

### 9.1 修改网站配置
在宝塔面板：
1. 点击 **网站**
2. 找到您的网站，点击 **设置**
3. 点击 **配置文件**
4. 替换为以下配置：

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 修改为您的域名或 IP
    
    # 根目录指向前端构建文件
    root /www/wwwroot/gaokongche/dist;
    index index.html;
    
    # 访问日志
    access_log /www/wwwlogs/gaokongche_access.log;
    error_log /www/wwwlogs/gaokongche_error.log;
    
    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    gzip_vary on;
    gzip_min_length 1024;
    
    # API 反向代理到后端
    location /api {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        
        # 超时设置
        proxy_connect_timeout 600;
        proxy_send_timeout 600;
        proxy_read_timeout 600;
    }
    
    # 上传文件路径
    location /uploads {
        alias /www/wwwroot/gaokongche/uploads;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # 前端路由处理（SPA）
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # 安全设置
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    
    # 隐藏 Nginx 版本号
    server_tokens off;
}
```

5. 点击 **保存**
6. 重载 Nginx 配置

### 9.2 配置 HTTPS（推荐）

2. 选择 **Let's Encrypt** 免费证书

## 十、配置 PM2 管理后端

### 10.1 创建 PM2 配置文件
```bash
cd /www/wwwroot/gaokongche
nano ecosystem.config.js
```

添加以下内容：
```javascript
module.exports = {
  apps: [{
    name: 'gaokongche-api',
    script: './server/index.js',
    cwd: '/www/wwwroot/gaokongche',
    instances: 2,  // 根据 CPU 核心数调整
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'production',
      PORT: 3001
    },
    error_file: './logs/pm2-error.log',
    out_file: './logs/pm2-out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
    merge_logs: true,
    autorestart: true,
    max_restarts: 10,
    min_uptime: '10s',
    max_memory_restart: '500M',
    watch: false
  }]
};
```

   - **运行目录**: /www/wwwroot/gaokongche
   - **端口**: 3001
   - **运行用户**: www
4. 点击 **提交**

## 十三、性能优化建议

### 13.1 MySQL 优化
```sql
-- 创建必要的索引
CREATE INDEX idx_company_id ON equipments(company_id);
CREATE INDEX idx_order_status ON orders(status);
CREATE INDEX idx_customer_company ON customers(company_id);

-- 定期优化表
OPTIMIZE TABLE equipments;
OPTIMIZE TABLE orders;
OPTIMIZE TABLE customers;
```

### 13.2 Nginx 优化
在 Nginx 配置中添加：
```nginx
# 连接优化
worker_processes auto;
worker_rlimit_nofile 65535;

events {
    worker_connections 10240;
    use epoll;
    multi_accept on;
}

http {
    # 缓存配置
    proxy_cache_path /var/cache/nginx levels=1:2 keys_zone=my_cache:10m max_size=1g inactive=60m;
    
    # 限流配置
    limit_req_zone $binary_remote_addr zone=api_limit:10m rate=100r/s;
}
```

### 13.3 Node.js 优化
```javascript
// server/index.js 添加集群模式

if (cluster.isMaster) {

    cluster.fork();
  }
} else {
  // 启动 Express 应用
}
```

```bash

chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```
