# 高空车租赁管理系统 - 宝塔部署快速参考

## 🚀 一键部署（推荐）

### 1. 准备工作
```bash
# SSH 连接到服务器
ssh root@your_server_ip

# 进入项目目录
cd /www/wwwroot
```

### 2. 执行自动部署脚本
```bash
# 下载项目
git clone https://github.com/liudaicai/gaokongche.git
cd gaokongche

# 给脚本添加执行权限
chmod +x scripts/deploy-baota.sh

# 运行自动部署脚本
./scripts/deploy-baota.sh
```

### 3. 部署后检查
```bash
# 给检查脚本添加执行权限
chmod +x scripts/check-deployment.sh

# 运行检查脚本
./scripts/check-deployment.sh /www/wwwroot/gaokongche 3001
```

## 📝 手动部署步骤

### 步骤 1: 创建数据库
在宝塔面板 → 数据库 → 添加数据库
- 数据库名: `gaokongche`
- 用户名: `gaokongche_user`
- 密码: 生成强密码
- 字符集: `utf8mb4`

### 步骤 2: 初始化数据库
```bash
cd /www/wwwroot/gaokongche/sql/mysql

# 执行初始化脚本
mysql -u gaokongche_user -p gaokongche < 000_init_database_baota.sql

# 执行核心迁移
mysql -u gaokongche_user -p gaokongche < 200_add_multi_tenant_support_safe.sql
mysql -u gaokongche_user -p gaokongche < 215_create_blacklist_table.sql
mysql -u gaokongche_user -p gaokongche < 217_merge_finance_SUCCESS.sql
mysql -u gaokongche_user -p gaokongche < 221_add_finance_records_fields.sql
```

### 步骤 3: 配置环境变量
```bash
cd /www/wwwroot/gaokongche
cp .env.example .env
nano .env
```

关键配置：
```env
DB_USER=gaokongche_user
DB_PASSWORD=your_password
DB_NAME=gaokongche
JWT_SECRET=生成32位以上随机字符串
API_PORT=3001
FRONTEND_URL=http://your-domain.com
```

### 步骤 4: 安装依赖和构建
```bash
# 配置 npm 镜像
npm config set registry https://registry.npmmirror.com

# 安装依赖
npm install --production

# 构建前端
npm run build
```

### 步骤 5: 启动后端服务
```bash
# 使用 PM2 启动
pm2 start ecosystem.config.js
pm2 save
pm2 startup

# 检查状态
pm2 status
pm2 logs gaokongche-api
```

### 步骤 6: 配置 Nginx
在宝塔面板 → 网站 → 添加站点 → 设置 → 配置文件

复制 `docs/宝塔部署指南.md` 中的 Nginx 配置

### 步骤 7: 测试访问
```bash
# 测试后端 API
curl http://localhost:3001/api/health

# 浏览器访问
http://your-domain.com
```

## 🔧 常用命令

### PM2 管理
```bash
pm2 status                        # 查看进程状态
pm2 logs gaokongche-api           # 查看日志
pm2 restart gaokongche-api        # 重启服务
pm2 stop gaokongche-api           # 停止服务
pm2 delete gaokongche-api         # 删除进程
pm2 monit                         # 实时监控
```

### Nginx 管理
```bash
nginx -t                          # 测试配置
nginx -s reload                   # 重载配置
systemctl status nginx            # 查看状态
systemctl restart nginx           # 重启服务
```

### 数据库管理
```bash
# 备份数据库
mysqldump -u gaokongche_user -p gaokongche > backup_$(date +%Y%m%d).sql

# 恢复数据库
mysql -u gaokongche_user -p gaokongche < backup_20240101.sql

# 进入数据库
mysql -u gaokongche_user -p gaokongche
```

### 日志查看
```bash
# 应用日志
tail -f logs/combined.log
tail -f logs/error.log

# PM2 日志
pm2 logs gaokongche-api --lines 100

# Nginx 日志
tail -f /www/wwwlogs/gaokongche_access.log
tail -f /www/wwwlogs/gaokongche_error.log
```

### 项目更新
```bash
cd /www/wwwroot/gaokongche

# 备份当前版本
cp -r dist dist.backup.$(date +%Y%m%d)

# 拉取最新代码
git pull origin main

# 安装新依赖
npm install --production

# 重新构建
npm run build

# 重启服务
pm2 restart gaokongche-api
```

## 🐛 常见问题

### 问题 1: 前端 404
```bash
# 检查 Nginx 配置
nginx -t

# 检查 dist 目录
ls -la /www/wwwroot/gaokongche/dist

# 检查文件权限
chown -R www:www /www/wwwroot/gaokongche
```

### 问题 2: API 连接失败
```bash
# 检查后端是否运行
pm2 status
netstat -tuln | grep 3001

# 查看后端日志
pm2 logs gaokongche-api --err

# 检查 .env 配置
cat .env
```

### 问题 3: 数据库连接失败
```bash
# 测试数据库连接
mysql -u gaokongche_user -p gaokongche -e "SELECT 1;"

# 检查 MySQL 状态
systemctl status mysql

# 查看数据库错误日志
tail -f /www/server/data/mysql-error.log
```

### 问题 4: 上传文件失败
```bash
# 检查 uploads 目录
ls -la uploads/

# 修复权限
chmod -R 755 uploads
chown -R www:www uploads

# 检查磁盘空间
df -h
```

### 问题 5: PM2 进程崩溃
```bash
# 查看崩溃日志
pm2 logs gaokongche-api --err --lines 50

# 删除并重新启动
pm2 delete gaokongche-api
pm2 start ecosystem.config.js

# 检查内存使用
pm2 monit
```

## 🔒 安全加固

### 1. 修改默认密码
```sql
-- 登录数据库
mysql -u gaokongche_user -p gaokongche

-- 修改管理员密码
UPDATE users SET password = '$2b$10$新的密码哈希' WHERE username = 'admin';
```

### 2. 配置 HTTPS
在宝塔面板 → 网站 → SSL → Let's Encrypt
- 申请免费证书
- 开启强制 HTTPS

### 3. 配置防火墙
```bash
# 只开放必要端口
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=443/tcp
firewall-cmd --reload

# 限制 3306 端口仅本地访问
firewall-cmd --permanent --remove-port=3306/tcp
```

### 4. 配置访问限制
在 Nginx 配置中添加：
```nginx
# IP 白名单（管理后台）
location /admin {
    allow 192.168.1.0/24;
    deny all;
}

# 限流
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=100r/s;
location /api {
    limit_req zone=api_limit burst=20;
}
```
