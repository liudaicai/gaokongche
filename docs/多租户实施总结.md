### 步骤4：改造核心路由（渐进式）

**推荐顺序**：
1. 先改造1-2个核心模块（如 `orders.mysql.js`）
2. 测试验证数据隔离效果
3. 逐步改造其他模块

**改造模板**（参考 `docs/多租户改造指南.md`）：

```javascript
// 1. 导入中间件
import { tenantMiddleware, setTenantId } from '../middleware/tenant.js';

// 2. GET 路由添加中间件 + WHERE过滤
router.get('/', tenantMiddleware, async (req, res) => {
  const { where, params } = req.tenantFilter;
  const sql = `SELECT * FROM table_name WHERE ${where}`;
  const [rows] = await pool.query(sql, params);
  res.json({ ok: true, data: rows });
});

// 3. POST 路由自动设置 company_id
router.post('/', tenantMiddleware, async (req, res) => {
  const data = setTenantId(req, req.body);
  const [result] = await pool.query('INSERT INTO table_name SET ?', [data]);
  res.json({ ok: true, id: result.insertId });
});
```
