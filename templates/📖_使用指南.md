# Word模板制作 - 快速使用指南

## 🎯 一分钟快速上手

### 第1步：查看可用变量
打开 **`变量速查表.txt`**，这里有所有可用的变量。

### 第2步：创建Word模板
1. 打开Word
2. 复制 `变量速查表.txt` 中的内容到Word
3. 调整格式（字体、段落、表格等）
4. 保存为 `.docx` 格式，文件名如：`租赁合同.docx`

### 第3步：放置模板
将 `.docx` 文件复制到本目录（templates文件夹）

### 第4步：使用
重启后端，系统会自动加载模板！

## ✍️ 基础语法（3种）

### 1️⃣ 显示单个值
```
客户名称：{{customerName}}
项目名称：{{projectName}}
总金额：{{totalAmount}} 元
```

### 2️⃣ 循环显示列表
```
设备清单：
{{#each equipments}}
{{index}}. {{code}} - {{model}} - {{dailyRate}}元/天
{{/each}}
```

### 3️⃣ 自动格式化
- 金额自动加千分位：`{{totalAmount}}` → 50,000.00
- 日期自动格式化：`{{startDate}}` → 2024/01/01

## ⚠️ 重要提示

### ✅ 必须做的
1. 文件保存为 `.docx` 格式（不是 .doc）
2. 变量名区分大小写：`{{customerName}}` ≠ `{{customername}}`
3. 循环必须配对：`{{#each}}` 和 `{{/each}}`

### ❌ 不要做的
1. 不要在Word中对 `{{变量名}}` 应用特殊格式
2. 不要手动添加千分位（系统自动处理）
3. 不要在变量中间换行

### 💡 小技巧
1. 在Word中直接输入 `{{变量名}}`，不要复制粘贴
2. 金额字段会自动格式化，直接使用即可
3. 如果变量为空，会显示空白（不会报错）

## 🎨 进阶技巧
