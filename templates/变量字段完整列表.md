## 🚜 三、设备列表（循环）

使用 `{{#each equipments}}...{{/each}}` 循环显示多台设备。

### 3.1 循环语法
```
{{#each equipments}}
序号：{{index}}
设备编号：{{code}}
型号：{{model}}
---
{{/each}}
```

### 3.2 设备字段
| 变量名 | 说明 | 类型 | 示例值 | 用法 |
|--------|------|------|--------|------|
| `{{index}}` | 序号（自动） | 数字 | 1, 2, 3... | `{{index}}` |
| `{{code}}` | 设备编号 | 文本 | EQ2024001 | `{{code}}` |
| `{{customCode}}` | 自定义编号 | 文本 | A-001 | `{{customCode}}` |
| `{{model}}` | 设备型号 | 文本 | 曲臂车16米 | `{{model}}` |
| `{{brand}}` | 设备品牌 | 文本 | 吉尼 | `{{brand}}` |
| `{{category}}` | 设备类别 | 文本 | 高空车 | `{{category}}` |
| `{{height}}` | 作业高度 | 文本 | 16米 | `{{height}}` |
| `{{dailyRate}}` | 日租金 | 金额 | 1,200.00 | `{{dailyRate}}元/天` |
| `{{monthlyRate}}` | 月租金 | 金额 | 30,000.00 | `{{monthlyRate}}元/月` |
| `{{quantity}}` | 数量 | 数字 | 1 | `{{quantity}}台` |

### 3.3 完整示例
```
设备清单：

{{#each equipments}}
{{index}}. 设备信息
   设备编号：{{code}}
   自定义编号：{{customCode}}
   设备型号：{{model}}
   品牌：{{brand}}
   类别：{{category}}
   作业高度：{{height}}
   日租金：{{dailyRate}} 元/天
   月租金：{{monthlyRate}} 元/月
   数量：{{quantity}} 台
   
{{/each}}
```

## 🎨 九、格式化说明

### 9.1 金额自动格式化
所有包含 `amount`、`Amount`、`price`、`Price`、`fee`、`Fee`、`cost`、`Cost`、`rate`、`Rate` 的字段会自动格式化为货币格式：

```
输入：50000
输出：50,000.00
```

### 9.2 日期自动格式化
所有日期字段会自动格式化为中文日期格式：

```
输入：2024-01-01
输出：2024/01/01
```

## 🔍 十一、使用技巧

### 11.1 条件判断（暂不支持，建议留空处理）
如果某个字段可能为空，建议在Word中这样处理：
```
备注：{{remarks}}（如果为空则显示空）
```

### 11.2 嵌套循环（支持）
可以在设备循环中嵌套其他循环：
```
{{#each equipments}}
设备：{{model}}
  配件：
  {{#each parts}}
  - {{name}}
  {{/each}}
{{/each}}
```

### 11.3 数字计算（需在后端处理）
如需要计算总金额，建议在后端先计算好：
```javascript
data.totalAmount = data.rentFee + data.transportFee + data.serviceFee;
```

## ⚠️ 十二、注意事项

1. **变量名区分大小写**：`{{customerName}}` ≠ `{{customername}}`
2. **循环必须配对**：`{{#each}}` 必须有对应的 `{{/each}}`
3. **空值显示**：如果数据中某字段为空，模板中会显示空白
4. **金额格式**：金额类字段自动添加千分位和小数点
5. **日期格式**：日期自动格式化为 YYYY/MM/DD 格式
